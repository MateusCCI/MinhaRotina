COMO EXECUTAR O MINHA ROTINA
=============================

NA NAVEGADOR
------------
    ./iniciar.sh

O ./iniciar.sh funciona de qualquer pasta, porque ele mesmo entra no
projeto. O comando direto abaixo precisa do cd:

Equivale a:

    cd /media/pam/Ext4Arquivos/Projetos/10-Projetos/10.05-MinhaRotina
    npx expo start --web

Depois de subir, acesse:  http://localhost:8081


NO CELULAR (QR do Expo Go)
--------------------------
    ./iniciar.sh fone

IMPORTANTE: rode num TERMINAL DE VERDADE. Se a saida for piped
(| head), guardada em arquivo ou launched com --fundo, o Expo NAO
desenha o QR — e o unico endereco que ele imprime e "localhost", que no
celular aponta para o proprio celular e nunca funciona. Foi essa a
origem de "tentei varias vezes e nao deu". O script imprime o
endereco exp:// correto mesmo sem QR.

O celular precisa estar NO MESMO Wi-Fi do computador.

Se o Wi-Fi tiver isolamento de cliente (APIs de hotel, rede
corporativa, faculdade), o celular chega mas o QR nao abre: use
hotspot inverso (o celular vira o roteador, o computador conecta nele)
ou rode com tunel:

    npx expo start --tunnel

Rota de reserva se nada funcionar na hora da banca: app ja instalado +
video de 60s (Risco 1 do TAP).

Equivale a:

    cd /media/pam/Ext4Arquivos/Projetos/10-Projetos/10.05-MinhaRotina
    npx expo start

Leia o QR code com o app Expo Go. Se o celular não conectar pelo Wi-Fi da
rede, use hotspot invertido ou rode com --tunnel.

Emulador ou aparelho Android conectado:
    ./iniciar.sh android


QUANDO A TELA FICAR BRANCA NO NAVEGADOR
---------------------------------------
    ./iniciar.sh --limpar

Equivale a:

    cd /media/pam/Ext4Arquivos/Projetos/10-Projetos/10.05-MinhaRotina
    npx expo start --web --clear

Limpa o cache do Metro. Se ainda assim ficar branca, recarregue forçado
duas vezes (Ctrl+Shift+R).


PARAR O SERVIDOR
----------------
    Ctrl+C                    (modo normal)

    pkill -f 'expo start'     (se ficou em segundo plano)


EM SEGUNDO PLANO
----------------
    ./iniciar.sh --fundo

Log em:  /tmp/minharotina-dev.log
Acompanhe com:  tail -f /tmp/minharotina-dev.log


AVISOS IMPORTANTES
------------------
- No navegador, use UMA aba por vez. O SQLite fica em OPFS e só uma aba
  pode usar o banco; com duas, a segunda mostra "Fechar as outras abas".

- O aviso de sistema (notificação) só funciona no celular. No navegador o
  aviso de fim de bloco vale apenas com o app aberto.

- Não abra o .docx do relatório para editar e salvar: o editor reescreve o
  XML interno e pode perder um parágrafo. Para mudar texto no relatório,
  use a ferramenta nota.
