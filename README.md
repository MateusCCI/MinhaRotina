# Minha Rotina — Projeto Integrador

Aplicativo mobile de organização de rotina para adultos com rotina variável e dificuldades de memória prospectiva (React Native + TypeScript + SQLite local).

## Disciplinas
- Programação para Dispositivos Móveis I
- Programação Orientada a Objetos
- Tópicos Avançados em Análises e Desenvolvimento de Sistemas
- Avaliação de Software

## Estrutura
```
docs/
├── TAP-PI-Minha-Rotina.md   # Termo de Abertura do Projeto
├── trabalho-pi.md           # Trabalho acadêmico (ABNT)
├── telas-minha-rotina.md    # Desenho das telas em texto
└── telas-minha-rotina.html  # Protótipo interativo das telas
```

## Protótipo
Abrir `docs/telas-minha-rotina.html` no navegador para navegar pelas telas (Inbox, Hoje, Saída, Timer, Revisão).
